# Elegant Fabrics - Premium Textiles Website

A modern, responsive website for a premium fabric and textiles company. This website showcases the company's story, values, team, and products with an elegant design and smooth user experience.

## 🌟 Features

### Design & User Experience
- **Modern & Elegant Design**: Clean, professional layout with premium aesthetics
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Smooth Animations**: Subtle animations and transitions for enhanced UX
- **Interactive Elements**: Hover effects, parallax scrolling, and dynamic content
- **Accessibility**: Semantic HTML and keyboard navigation support

### Pages & Sections
- **Home Page**: Hero section, product showcase, and contact form
- **About Us Page**: Company story, values, mission, team, and certifications
- **Navigation**: Fixed header with smooth scrolling and mobile menu
- **Contact Form**: Functional contact form with validation

### Technical Features
- **Pure HTML/CSS/JavaScript**: No frameworks required
- **Cross-browser Compatible**: Works on all modern browsers
- **Performance Optimized**: Fast loading with optimized assets
- **SEO Friendly**: Semantic markup and meta tags
- **Mobile First**: Responsive design approach

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software or dependencies required

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. Navigate through the website using the navigation menu

### Local Development
For local development, you can use any local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

## 🔧 Customization

### Colors
Update the CSS custom properties in `styles.css`:

```css
:root {
    --primary-color: #e74c3c;
    --secondary-color: #2c3e50;
    --accent-color: #34495e;
    --background-color: #f8f9fa;
    --text-color: #333;
}
```

### Content
- Edit text content directly in the HTML files
- Update company information in `about.html`
- Modify product details in `index.html`
- Change contact information in both files

### Styling
- Modify `styles.css` for design changes
- Add new sections by following the existing CSS patterns
- Update animations in the JavaScript file
